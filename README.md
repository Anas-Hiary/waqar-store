# متجر وَقّار للملابس الرجالية | السلط - الأردن
## Waqar Men's Fashion E-Commerce Platform

متجر إلكتروني متكامل واحترافي مصمم خصيصاً للملابس الرجالية الفاخرة باسم **"وَقّار"** في السلط، الأردن.

---

### ✨ المميزات الرئيسية للمتجر (Store Features)

1. **تخصص حصري بالأزياء الرجالية (Men's Clothing Only)**:
   - قمصان، تيشيرتات، بناطيل، جينز، جاكيتات، بدلات، أطقم، ملابس رياضية، ملابس شتوية، ملابس صيفية.
   - لا يحتوي على أي إكسسوارات أو ملابس نسائية أو أطفال.

2. **تصميم فاخر وعصري (Masculine Luxury UI/UX)**:
   - نظام ألوان فخم (الأسود، الفحمي الداكن، الأوف وايت، مع لمسات ذهبية راقية).
   - خطوط عربية حديثة (**Tajawal** و **IBM Plex Sans Arabic**).
   - تصميم متجاوب بالكامل مع الهواتف المحمولة أولاً (Mobile-First) مع شبكة منتجات عمودين وشريط تنقل سفلي ثابت.

3. **لوحة تحكم Admin شاملة ومؤمنة بالكامل (`/admin`)**:
   - **إحصائيات وتقارير**: رسوم بيانية تفاعلية، إجمالي المبيعات، الطلبات، تنبيهات المخزون المنخفض.
   - **إدارة المنتجات**: إضافة وتعديل وحذف وتكرار المنتجات، رفع الصور المتعددة وتحديد الصورة الرئيسية.
   - **مصفوفة المتغيرات والمخزون (Variant Matrix)**: تحديد الألوان والمقاسات والمخزون الفعلي لكل تركيبة بدقة.
   - **إدارة الطلبات**: تغيير الحالات (جديد، قيد التجهيز، تم الشحن، تم التسليم، ملغي) مع طباعة فواتير مخصصة.
   - **إدارة التصنيفات الرجالية**: إضافة وتعديل وترتيب التصنيفات.
   - **رسوم التوصيل والمحافظات**: تخصيص أسعار التوصيل (السلط، عمان، الزرقاء، إربد، باقي المحافظات).
   - **كوبونات الخصم**: إنشاء قسائم خصم بنسبة مئوية أو مبالغ ثابتة مع حدود دنيا وصلاحيات.
   - **تقييمات العملاء**: مراجعة واعتماد أو رفض التقييمات.
   - **محرر الصفحة الرئيسية**: تعديل البانر، العناوين، الأزرار، والبطاقات الترويجية بدون لمس الكود.
   - **إعدادات المتجر وأمان المدير**: تغيير أرقام الهواتف، الواتساب، الإنستغرام، ساعات العمل، وكلمة مرور المدير المشفرة.

4. **تجربة تسوق وسلة وإتمام طلب متطورة**:
   - سلة شراء تفاعلية مع حساب تلقائي لرسوم التوصيل حسب المحافظة المختارة.
   - إتمام طلب سهل مع التحقق من أرقام الهواتف الأردنية (`0796667505`).
   - خيار الدفع نقدًا عند الاستلام (Cash on Delivery).
   - شاشة تأكيد مع رقم طلب فريد (مثل `#WAQ-1001`) وزر تواصل فوري عبر الواتساب.
   - صفحة تتبع الطلبات مع خط زمني تفاعلي للمراحل.
   - تكامل متقدم ومباشر مع الواتساب (+962796667505) وإنستغرام (@waqar_fashion199).

### 🚀 تشغيل المتجر (How to Run)

1. تشغيل الخادم:
   ```bash
   python run.py
   ```

2. الروابط المباشرة:
   - **واجهة المتجر**: `http://127.0.0.1:5000`
   - **لوحة التحكم**: `http://127.0.0.1:5000/admin`

3. **بيانات تسجيل دخول المدير الافتراضية**:
   - **اسم المستخدم (Username)**: `admin`
   - **كلمة المرور (Password)**: `admin123`
   *(يمكن تغييرها في أي وقت من قسم إعدادات المتجر والحساب في لوحة التحكم)*
